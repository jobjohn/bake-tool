# Bake Tool

ハイポリ → ローポリのノーマル／カラーを、ボタン一つでベイクする Blender アドオンです。

- ベイク結果は `.blend` と同じフォルダに PNG で保存（`<dst名>_normal.png` / `<dst名>_color.png`）
- 保存した画像を dst のマテリアル（プリンシプルBSDF）に自動でつなぐ
- dst にマテリアルや UV がなければ自動で作る（任意）
- 押し出し距離はサイズ差から自動計算（0 = 自動）
- 設定はシーンに保存されるので、試行錯誤しやすい

動作確認: Blender 5.2

## インストール

1. [Releases](../../releases) から `bake_tool.py` をダウンロード
2. Blender の「編集 → プリファレンス → アドオン → ディスクからインストール」で `bake_tool.py` を選び、有効にする
3. 3D ビューで N キー →「Bake」タブ

## 使い方

1. `.blend` を一度保存する
2. オブジェクトモードで「ノーマルをベイク」または「カラーをベイク」を押す
3. ダイアログで設定して OK

| 項目 | 内容 |
|---|---|
| src（ハイポリ） | 写し取る元。空なら dst 単体でベイク |
| dst（ローポリ） | 書き込む先。マテリアルと UV が必要 |
| 押し出し距離（0=自動） | ベイクに穴や黄色い崩れが出たら大きくする |
| 解像度 | 出力画像のサイズ |

初回はアクティブなメッシュが dst、もう一つの選択メッシュが src に入ります。2 回目以降は前回の設定が残ります。

## 注意

- 同名の PNG は確認なしで上書きされます
- src / dst が非表示だとベイクできません
- カラーはライティングを含まない素の色（Diffuse の Color のみ）です

## テスト

```bash
blender -b --factory-startup --python test_bake_tool.py -- <空の作業フォルダ>
```
